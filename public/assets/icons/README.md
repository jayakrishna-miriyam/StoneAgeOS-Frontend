# Icon Asset Paths

## Weather Animated Icons (Basmilius)
Save animated weather icons here:

- `frontend/public/assets/icons/weather/animated/`

Recommended file names:

- `clear-day.svg`
- `clear-night.svg`
- `partly-cloudy-day.svg`
- `partly-cloudy-night.svg`
- `overcast.svg`
- `fog.svg`
- `rain.svg`
- `drizzle.svg`
- `thunderstorms.svg`
- `snow.svg`
- `sleet.svg`
- `wind.svg`

## Thiings Icon Sets
Save generated Thiings assets here:

- `frontend/public/assets/icons/thiings/futuristic-caveman/` (hero/decorative accents)

Optional subfolders (create only when needed):

- `frontend/public/assets/icons/thiings/ui/`
- `frontend/public/assets/icons/thiings/needs/`
- `frontend/public/assets/icons/thiings/status/`

PNG or SVG both work. Prefer SVG when available.
